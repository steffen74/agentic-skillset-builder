# Role: router

**Job.** Tell the user which skill fits now. One skill to remember instead of many; it hints, never fires.

**Steps.** Read the canvas and the skillset's section of `AGENTS.md`; if either is missing, the answer is the setup skill. Then recommend **one** next skill, with one sentence on why, from a table of *if … → recommend* rows in process order, each row a gap that can be seen in the project files (an empty block, a file without a status, a signal without a fix). When two rows apply, the earlier wins; name the exception that overrides order (a deadline, a session within seven days).

**Done when** the user has one recommendation with its reason.
