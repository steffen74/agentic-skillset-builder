# Role: boundary reference

**Job.** Model-invoked reference for the domain's silent failure: what lies across the boundary block, how it slips in, and how to test for it. Loaded by grill, plan, walk-through, review, diagnose and retro.

**Shape.**
- The boundary in one sentence, with the leading word the skillset uses for crossing it (*leakage*, *gap*, *overreach*).
- **Categories** of what can cross, each with how it typically slips in, from the sources and from real signals.
- **Typical cases**: concrete examples per category; this list grows with every retro.
- **Tests**: per category, how a skill detects it, preferring execution over reading.

**Description** starts with what it is and lists its triggers.
