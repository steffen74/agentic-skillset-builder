# Role: plan

**Job.** Turn the canvas into the written plan every later skill builds from (adapted from Matt Pocock's `to-spec`). No interview: if the purpose blocks are empty, stop and suggest the grill skill.

**Steps.**
1. *Draft* the plan file with its parts: the sequence of work items, an **alignment matrix** (purpose items × work items, so every goal is served and every work item serves a goal), the growth of the boundary over the sequence, and the effort against the budget.
2. *Stop point*: present the problems first (unserved goals, items used before they are inside the boundary, over budget), each with a recommended fix. The user decides; log structural choices.
3. *Checks*: add the plan-level checks the user confirmed to the checks file (format from the checks reference).

**Done when** the user has confirmed the plan and every problem is fixed or open with an owner.
