# Role: inventory

**Job.** Collect the facts the design must fit into: the 🤖 blocks of the purpose and design columns (data, resources, constraints, market facts). Facts only; every judgement found on the way becomes a question.

**Steps.**
1. *Collect* from every location the setup recorded and every source the user named: read, count, measure, execute where possible. Open every source and check the fact is there; a search snippet is not a source. Record where each fact comes from and when it was read. Input the user pastes into the chat is copied verbatim into the project file first. "Not found" is not a fact; record it with date and search terms.
2. *Find problems*: contradictions between sources, missing facts, facts that change the purpose (a dataset that cannot answer the question, a market smaller than assumed), visibility or license issues.
3. *Stop point*: present the inventory with the problems first; for each, the decisions it raises, as multiple-choice questions with their own context.

**Done when** every location is inventoried, every fact has a source, and every raised decision is logged or listed as an open question.
