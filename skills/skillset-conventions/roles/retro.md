# Role: retro

**Job.** After a milestone or when something went wrong: turn what happened into fixes now, checks, boundary entries, canvas changes and improvements to the skillset itself (adapted from Matt Pocock's `retro`).

**Steps.**
1. *Collect signals* in one round of questions, plus facts the agent can look up; each into the signal log, without personal names.
2. *Explain each signal* before proposing: find the cause (load the boundary reference), then ask **why no check caught it**. That answer matters more than the fix.
3. *Propose*, numbered, with evidence and a recommendation: **fix now**; **check** (with type); **boundary**; **canvas and plan**; **skill rule**, written to a named project file (e.g. `SKILL-PROPOSALS.md`) as one plain sentence followed by a diff against the skill file, to file as an issue in the skillset repo. Prefer a check over a rule.
4. *Apply* only what the user picks; set each signal's status; update the improvements block.

**Done when** every picked item is written to its file and every signal has a status.
