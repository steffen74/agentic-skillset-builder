# Personas

## Ines: instructor with a method, new to skills

- **Setting:** teaches a course at opencampus.sh built around a canvas or method; wants an agentic version for participants; a few evenings of time.
- **Domain knowledge:** expert in the method and its handbook; knows the typical mistakes participants make.
- **Agent experience:** uses Claude Code for writing and small scripts; has installed skills, never written one; reads Markdown.
- **Has:** a published handbook, a GitHub account, no repository for the skillset yet.
- **Language:** German; reads English.
- **Typical failure without the builder:** copies an existing skillset and edits it; leaves data-science leftovers in skills, forgets the core files, never tests a skill as a participant.
- **Source:** assumption, based on opencampus.sh instructors.

## Steffen: maintainer of the existing skillsets

- **Setting:** maintains Agentic Data Science and Agentic Course Creation, builds the next skillset.
- **Domain knowledge:** knows the blueprint, Matt Pocock's skills and the conventions.
- **Agent experience:** writes skills; works in cloud and local sessions.
- **Has:** GitHub with push rights, the sibling repositories.
- **Language:** German and English.
- **Typical failure without the builder:** fixes in one skillset that never reach the others.
- **Source:** the maintainer.
